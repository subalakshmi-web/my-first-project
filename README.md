# 🎓 Student Task Manager

A simple web application designed to help students manage their daily college tasks.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- View total, completed and pending tasks
- Saves tasks using browser Local Storage
- Simple and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Purpose

This project was created to practice web development, JavaScript and basic CRUD operations.
